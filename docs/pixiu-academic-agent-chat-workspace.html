Retrieval-Augmented Generation for Knowledge-Intensive NLP Tasks

Patrick Lewis, Ethan Perez, Aleksandra Piktus 等 · Pixiu 论文库节选视图

Abstract

本文研究如何让参数化生成模型与非参数化记忆结合，以完成知识密集型自然语言处理任务。核心思想是将检索到的文档片段作为生成条件，从而提升答案的事实性与可追溯性。这种方式使模型能够在无需完全重新训练的情况下访问外部知识。

2. Retrieval-Augmented Generation

在 RAG 框架中，输入问题首先被送入检索模块，检索模块从大规模文档集合中返回若干相关段落。随后生成模型基于问题与检索段落共同生成最终回答。与纯参数模型相比，该框架把知识来源显式暴露出来，因而更适合需要引用依据的学术阅读、开放域问答和研究辅助任务。

对 Pixiu Academic Assistant 而言，这种机制可以直接映射为“证据追溯”：AI 的每个回答不仅给出结论，还要返回论文名、章节、页码和原文摘要，帮助研究者快速判断观点是否可信。

请解释 Methods 里 RAG 的核心流程。
RAG 的流程可以拆成三步：先把问题编码成检索向量，再从论文或知识库中召回相关段落，最后让生成模型同时参考问题与证据生成回答。
它和 Agent 研究模式有什么区别？
阅读 IDE 围绕单篇 PDF；Agent 研究模式会把多篇论文作为项目资源，自动规划任务、调用工具、比较证据，并生成跨论文研究产物。
