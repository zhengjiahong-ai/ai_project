# 阶段 3 验收：新手引导学习闭环

日期：2026-10-08。状态：阶段 3 完成；完整产品与新手观察尚未验收。

## 实际验证范围

在真实论文 Active RIS-Assisted Integrated Sensing and Communication Systems 上，用配置的真实 Provider 验证一个基础概念：主动 RIS 为什么能反射并放大信号。脚本中的学生回答是验收输入，不能冒充实际新手观察或证明所有学科教学质量。

| 要求 | 实际证据 |
| --- | --- |
| 根据目标选择起点，不先填档案 | 用户目标只学一个概念、暂不涉及公式；真实精读返回一个概念、简短解释及一个问题，`novice-start-runtime.json` |
| 精读先解释、自测先作答 | 精读有引用支持的解释；独立自测一个概念且没有答案/解释，`quiz-start-runtime.json` |
| 错误回答 | 原文区分无源反射单元与有源负载，真实返回 incorrect，说明混淆并引用两段原文，`novice-incorrect-runtime.json` |
| 部分正确回答 | 认可反射/放大，指出缺少有源负载的因果解释，partial，不推进当前概念，`novice-partial-runtime.json` |
| 针对性补课 | 首轮错误否认已有回答，保留失败证据；提供同概念最近答案与反馈后，围绕该错误解释/引导，`novice-remediate2-runtime.json` |
| 正确回答及完成提示 | demonstrated、缺口为空；不再重复已答问题，仍可追问/显式结束，`novice-correct-runtime.json`、`quiz-correct-runtime.json` |
| 资料不足 | 论文未提供 BC547 型号与固定增益；真实返回 unassessable，不判错、不标记掌握、不新增伪造补课缺口，`novice-unassessable-runtime.json` |
| 临时追问 | 首轮重复旧评价，保留失败记录；修复后直接回答主动/无源区别、evaluation=null、掌握状态/概念不变，`novice-ask2-runtime.json`。浏览器旧追问成功后自动回到作答，过程未重跑 |
| 暂停、继续、阅读焦点变化 | 阶段 2 已实际验证中栏 B、活动 A 的暂停/继续，原问题/身份保留、无模型调用；本阶段沿用该可靠控制路径 |
| 跳过、重答、结束 | 真实重答恢复待回顾，跳过不标记掌握；精读结束保留 skipped、自测结束保留 demonstrated，`novice-retry-runtime.json`、`novice-skip-runtime.json`、两份 finish 记录 |
| 保存与刷新 | 结束后真实 GET 的活动身份、状态及概念与原响应一致，消息和材料保留，`learning-closure-runtime.json`；浏览器刷新后可见保存记录 |
| 来源与评估 | 聚合验收逐项核验所有评价引用的 sourceId 和逐字正文摘录，判定/状态与案例匹配；没有把检索覆盖分数或来源列表当作掌握证明 |

证据与查询脚本位于 `stage2-evidence/`；提交前查询固定身份，正在运行只查询，不因观察超时再调用模型。一次控制仍 queued 时的后续请求被 409 拒绝，确认控制成功后才提交下一步，没有调度重复模型。

## 实现与回归

- 学习对象与材料快照不随中栏改变；精读解释引用按概念保留，进入下一概念时带上对应来源。
- 不按固定题数结束；只有逐概念有引用支持的回答才能标记 demonstrated，证据不足不判错。
- 临时追问模式按任务/活动隔离，处理时禁用切换，成功后恢复作答；已核验后默认继续追问，重答重新进入待回顾。
- 同一活动的保存版本在导航中只显示一个活动记录，完整原始历史不删除。
- 研究查询错误按所属任务隔离；恢复后清除对应轮询提示，保留未确认的操作错误。任务 ID 含分隔符也不会串提示。开发热更新的旧临时键不会让界面崩溃。
- Python 相关 55 项通过；前端完整 31 文件 195 项通过，后续研究错误键修复相关 5 项通过，类型检查通过，构建通过。
