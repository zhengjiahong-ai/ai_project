## 二、项目背景与用户痛点

### 1. 项目背景与
学生和科研初学者在阅读英文学术论文时，面临的困难远不止语言层面：
- 论文本身的阅读阻力：术语、方法和实验细节理解成本高。
- 学习者自身的知识缺口：不清楚该补哪些**前置知识**，且在大模型流畅的回答下难以**判断自己是否真正掌握**。
- 论文的“伪贡献”风险：论文可能存在**过度表述**，宣称的创新有时只是已有方法的组合或包装。
- 通用 AI 工具的能力边界：普通问答工具能回答问题，却很难把论文阅读**进一步推进到跨论文比较和开放研究问题**。

本项目希望构建的系统能做到进一步帮助用户理解论文、追问论文、评价论文，并把单篇阅读延伸到多篇论文的持续研究。

### 2. 项目目标

打造一个面向学术论文阅读与研究场景的 AI 学习工作台，支撑用户完成“**上传论文 → 结构化解析 → 对话问答 → 术语解释 → 逐页翻译 → 批判性分析 → 背景补课 → 引导学习 → 深度研究 → 多论文 Agent 研究**”的完整学习与研究流程。

### 3. 具体目标

- **阅读辅助**：围绕单篇论文打通“输入—理解—追问—分析”的连续工作流。
- **研究推进**：把阅读从单篇推进到多篇论文的内容聚合与研究报告。

## 三、项目创新点

围绕二.1 提出的四类用户痛点，本项目在通用问答工具之外形成**四个核心创新点**，并以"人在回路 + 证据可溯源"作为贯穿性设计原则。

### 1. 证据化批判性阅读——识别论文"伪贡献"

对应痛点：论文的"伪贡献"风险。

- 从**贡献、方法、实验、局限**四个维度进行证据化分析，输出 **真实贡献 / 薄弱点 / 夸大风险 / 缺失证据** 四类明确标记；
- **区别于通用摘要工具**：不复述作者主张，而是评价"主张是否有证据支撑"。

### 2. 分层背景补课——按需生成概念图谱与学习路径

对应痛点：不清楚该补哪些前置知识。
- 按用户当前水平生成个性化概念图谱，学习路径分 **基础概念 → 方法前置 → 实验理解 → 批判视角** 四层；
- **区别于通用大模型**：不是泛泛讲背景，而是围绕当前论文的具体概念依赖图。

### 3. 苏格拉底式引导学习——从"AI 讲懂了"到"用户真懂了"

对应痛点：在大模型流畅回答下难以判断自己是否真正掌握。

- **五轮递进问题**覆盖研究问题、方法创新、方法逻辑、实验依据、局限改进；
- 用户主动作答而非被动接收，给出**掌握度评估、证据质量评分与回读建议**；
- **区别于普通问答**：不是直接给答案，而是通过提问暴露用户理解盲点。

### 4. 深度研究 + 多论文 Agent——把阅读推进到研究

对应痛点：通用 AI 工具很难把论文阅读进一步推进到跨论文比较和开放研究问题。

- **单论文深度研究**：把研究问题拆为 3–5 个子问题，迭代检索形成结构化研究报告；
- **多论文 Agent**：跨论文证据聚合，自动归纳 **共识 / 互补 / 矛盾 / 空白**，对结论不一致处进行冲突识别与裁决；




## 四、功能与应用效果
### 1. 论文 阅读 IDE 
#### 基础能力
- **PDF 上传与篇章解构**：调用 GROBID 结构化解析标题、摘要、章节和正文片段，作为后续功能基础。
- **论文问答与划词解释**
	- 检索当前论文，结合意图识别和证据判断生成回答；
	- 划词可动态解释术语。
- **逐页翻译**：围绕当前 PDF 版面翻译，对图表区域留空以保留排版对应关系。
#### 进阶功能
- **批判性阅读**：围绕贡献、方法、实验、局限四个维度进行证据化分析，标记真实贡献、薄弱点、夸大风险和缺失证据，**针对论文伪贡献问题**。
- **背景补课**：分两阶段识别概念与前置关系，**按知识水平生成概念图谱与学习路径**。
- **苏格拉底式引导学习**：通过五轮递进问题**引导用户**围绕研究问题、方法创新、方法逻辑、实验依据和局限改进**主动学习**，给出掌握度评估与回读建议。
- **深度研究（Deep Research）**：把研究问题拆为 3–5 个子问题并调度检索，实现**迭代深度研究**

### 2. 多论文 研究Agent 

面向“同时读多篇论文、做跨论文研究”的场景，把单篇阅读延伸到多篇论文的证据化研究：

- **多论文研究项目**：创建研究项目，从论文库多选论文纳入同一研究；从阅读 IDE 进入时，当前论文自动作为默认选中论文。
- **研究计划可审可改**：系统先生成研究计划，用户可在执行前审查——增删改研究方向、指定重点论文、调整研究范围，确认后才开始检索分析。
- **跨论文证据聚合**：围绕研究问题跨多篇论文检索证据，自动归纳论文间的**共识、互补、矛盾与空白**。
- **冲突识别与提示**：对论文之间结论不一致的地方给出标记
- **结构化研究报告**：自动产出含摘要、共识发现、争议发现、单源发现的报告，并对每条结论标注证据可信度与置信度。



## 五、应用场景

系统面向两类典型使用场景：**单篇论文精读**与**多篇论文研究**。两者通过论文库与阅读 IDE 的"推荐下一步"衔接，构成完整的"读—问—评—研"工作流。

### 1. 单篇论文精读：从"看不懂"到"能评价、能追问"

面向初次接触某领域科研论文的用户，围绕一篇论文完成"输入 → 理解 → 追问 → 评价 → 研究"的连续阅读。

1. **上传论文，建立结构化底座**：在阅读 IDE 中上传 PDF，系统调用 GROBID 完成篇章解构，得到标题、摘要、章节骨架与可检索片段，作为后续所有功能的基础。
2. **边读边问，扫清理解障碍**：
	- 对看不懂的段落直接在问答面板提问，回答附**带页码的来源标签**，可跳回 PDF 原文核对；
	- 遇到术语**划词解释**，并围绕同一段文字继续追问；
	- 进入**逐页翻译**，图表区域留空以保留版面，译文与原文逐页对应。
3. **补齐前置知识**：当发现读不懂是背景不足时，进入**背景补课**——设定当前水平、学习目标与卡点，系统按论文主题生成概念图谱与学习路径，把补课内容组织为"基础概念 → 方法前置 → 实验理解 → 批判视角"四层，先补再读。
4. **主动检验掌握度**：进入**苏格拉底式引导学习**，系统围绕研究问题、方法创新、方法逻辑、实验依据、局限改进提出**五轮递进问题**；用户用自己的话作答，系统给出掌握度评估、证据质量评分与回读建议，专门解决"看懂了 AI 讲解、其实没真正掌握"的问题。
5. **对论文本身做出评价**：进入**批判性阅读**，系统从贡献、方法、实验、局限四个维度输出**真实贡献 / 薄弱点 / 夸大风险 / 缺失证据**四类证据化标记，直接回应"论文伪贡献"风险，让用户不再只是接受作者主张。
6. **把阅读推进到开放研究**：需要进一步追问"这个方向还能怎么做"时，进入**深度研究（Deep Research）**——填写研究目标 → 系统生成 brief 预览并拆解为 3–5 个子问题 → 用户**审查计划**（可增删改子问题、填写备注）→ 确认后系统调度检索 → 执行中可查看 finding、证据、覆盖率、冲突与 trace → 草稿完成后进入**终稿人工确认**，逐项标记"已核查 / 仍需跟进"，得到一份可溯源的结构化研究报告。

### 2. 多论文研究 Agent：从"读过几篇"到"跨论文证据化结论"

面向已经完成若干篇单论文阅读、需要跨论文比较与综合的用户，把散点连成有证据的结论。

1. **建项目、聚合论文**：切换到"Agent 研究"，创建项目并从论文库多选论文纳入同一研究；从阅读 IDE 的"推荐下一步"进入时，当前论文自动作为默认选中论文。
2. **提任务、审计划**：在输入框中给出具体研究问题（如"比较这些论文的研究问题、方法设计、实验指标与局限性"），系统先生成研究计划——包含研究指令、focused papers 与约束；**用户在执行前审查计划**，可增删改研究方向、指定重点论文、调整研究范围，确认后才开始跨论文检索。
3. **阅读结构化研究报告**：任务完成后生成报告，按四个章节组织，每条结论附**证据可信度与置信度徽标**，点击来源标签可跳回对应论文 PDF 页面：


### 3. 全流程闭环

单篇精读与多篇研究并非割裂——阅读 IDE 中可通过"推荐下一步"带着当前论文进入 Agent 项目；Agent 研究中点击任意证据来源，也会回到阅读 IDE 定位到具体论文与页面。整套流程完整覆盖"**上传论文 → 结构化解析 → 对话问答 → 术语解释 → 逐页翻译 → 批判性分析 → 背景补课 → 引导学习 → 深度研究 → 多论文 Agent 研究**"的学习与研究路径，与二.2 中提出的总体目标一一对应。
