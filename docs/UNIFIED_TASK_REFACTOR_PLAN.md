## 1. 产品要求

### 1.1 任务和上下文

- 任务组织论文、主对话、学习活动、笔记与成果；可以创建、切换和重命名。首次使用直接上传或输入目标，不强制填写研究档案。
- 同一任务所有材料默认可供 AI 检索，不表示把全部全文塞入每个请求。
- 作用域优先级：用户显式指定或“只根据”约束 > 正在继续的活动对象 > 单篇指代与阅读焦点 > 当前任务全部材料。
- 每次发送固定任务 ID、材料 ID 集合、焦点、选区、活动 ID 和用户约束快照。切换任务或论文不改变运行中的请求对象，迟到响应不能写入另一个任务。
- 以焦点论文为主可以使用任务内其他论文解释或比较；严格单篇约束不得引用其他论文。回答中的归属必须正确。
- 点击引用改变阅读位置，不改变精读等已有活动对象。明显歧义简短澄清。

### 1.2 三栏与原文

- 从左到右是导航、论文/成果阅读、对话。全部可收起并恢复、调整宽度；至少保留一个主内容区。
- 导航包含任务切换、论文材料、当前论文目录、笔记成果。单篇和多篇没有分离的主页面。
- 并排、专注阅读、专注对话布局可切换并恢复。
- PDF 页码、目录、划词解释、标注、引用定位保留。全景翻译属于阅读显示模式，提供原文/译文或对照。
- 短划词解释在原文旁呈现；继续讨论才进入对话并携带选区来源。
- 完整笔记和长报告在中栏打开；对话显示结果摘要与入口，保留 PDF 标签或返回位置。

### 1.3 对话能力

- 自然语言与 `/精读`、`/补课`、`/自测`、`/批判`、`/比较`、`/研究` 使用相同执行路径。`@材料` 用于明确指定，任务默认范围不依赖手动标签。
- 综合 Agent 是内部编排能力，用户不必切换到另一个 Agent 页面。开放问题能够组合检索、比较、批判和研究。
- 简单问题直接回答，不自动放大成长研究。长研究提供简洁可调整计划，执行中可停止，失败可重试或恢复。
- 引导学习支持针对性提示、补课、重新作答、跳过、暂停和继续；临时术语提问不丢失活动位置。禁止以固定题数、翻页或操作次数冒充掌握程度。

### 1.4 结果和成果

- 结果优先，引用为紧邻断言的小标记，来源详情点击展开，工具轨迹默认折叠。
- 执行中最多一行主要状态和停止入口。不得用大量过程卡片、模型评分、检索计数占据结果主体。
- 保留适合内容的输出：回答、互动问题、批判判断、比较表、报告。统一保存、引用、重试、继续讨论的行为。
- 普通回答主动保存；比较表、研究报告等正式成果自动归属当前任务。不能仅把长文本输出包装成旧面板算统一完成。
- 用户编辑、AI 原始内容及后续版本能够区分；预览、复制、下载使用同一份最新内容。
- 笔记可以关联多篇论文，来源默认折叠。支持移动、导出、恢复；不自动把保存 AI 答案当作已理解。

## 5. 验证与最终交付

- 每个代码批次做针对性测试；相关批次完成后运行 frontend typecheck、test、build 及后端涉及服务测试。
- 重点测试范围/持久化/任务切换等真实风险，不能只断言自身返回值或替真实链路造假。
- Playwright fixture 可证明 UI 分支与接口契约；必须与真服务/真 Provider 的验证报告分开。
- 最终生成验收报告，逐项引用本矩阵，记录已完成、尚缺、限制与复现命令。没有覆盖完整范围时，不得把整个重构标为完成。
- 主要验收路径：创建任务 → 加入论文 A → 精读 → 原文定位与补课 → 用户作答 → 加入 B → 比较 → 保存/编辑总结 → 关闭重开继续。
