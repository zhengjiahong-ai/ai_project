# 受限代码执行安全计划

## 状态与目的

本文固定 P5 阶段的唯一允许场景和安全非目标。P5-07 已增加固定 CSV 暂存、执行前审批、隔离执行和产物发布前审批 API/UI，但仍不提供 Agent/MCP 工具或通用代码执行入口。P5-02 实测选择的加固 Docker Linux 容器继续作为隔离边界，详见 [`code_sandbox_benchmark.md`](code_sandbox_benchmark.md)。

唯一允许场景是：对用户明确确认的一份 CSV artifact，使用不可修改的 Python 3 固定模板生成描述统计。系统不是通用编程代理，用户输入、论文内容和模型输出都不能成为代码、表达式、模块名、文件路径或运行参数。

## 允许范围

### 输入

- 每个任务只接受一个已由用户确认的 artifact ID；现有前端研究卡片不自动成为可执行输入。
- artifact 内容必须是带唯一非空表头的 UTF-8 纯文本 CSV，分隔符固定为英文逗号。
- Worker 未来只能获得隔离层提供的只读输入句柄或固定挂载点，不能接受用户提供的宿主路径、URL 或文件 URI。
- 不接受 XLS/XLSX、JSON、压缩包、数据库、目录、多文件、符号链接、设备文件或命名管道。
- CSV 单元格一律视为不可信数据。以 `=`, `+`, `-`, `@` 开头的公式样式文本不得计算、展开或传递到可执行表格格式。

### 运行时与库

- 语言固定为 Python 3.13.9；基础镜像按 registry digest 固定，Worker 任务按本地不可变镜像 ID 固定，镜像变化会改变任务审批摘要。
- 分析模板只允许使用 Python 标准库 `csv`、`statistics`、`math` 和 `json`。
- 用户、模型和 Agent 不能提交、生成、拼接或修改脚本；模板变化属于代码发布，必须重新测试并使既有审批失效。
- 不允许 pandas、numpy、第三方插件、动态 import、反射式模块加载或运行时依赖下载。

### 操作与输出

- 允许统计：总行数、各列缺失值数、数值列有效值数、最小值、最大值、均值、中位数、样本标准差和四分位数。
- 非有限数、混合类型、空列、重复表头、畸形行和无法解码内容必须产生有界警告或封闭式失败，不能猜测修复或执行数据清洗。
- 输出仅为有界结构化 JSON，包含统计结果、警告、模板/运行时标识、输入输出 digest、资源限制和退出状态的审计摘要。
- 输出不得包含原始数据行、无限长度样本、任意文件、脚本、HTML、图表或可执行内容，也不得自动进入研究报告或 Agent evidence。

## 明确禁止与安全非目标

- 禁止 Shell、命令解释器、子进程、进程树、交互式解释器、长期进程、后台任务和计划任务。
- 禁止 `eval`、`exec`、任意表达式、用户代码、模型生成代码、动态 import、包安装和编译扩展。
- 禁止任意网络、DNS、代理、回环地址、云元数据服务和 Provider API。
- 禁止访问宿主文件系统、用户目录、项目源码、版本库、Docker socket、容器管理接口、共享内存、环境变量和凭据。
- 禁止把 CSV 文本解释为提示、工具指令、公式、路径、URL、模板或配置。
- 禁止将此能力描述为通用数据科学、自动编程、任意 Python、`run_shell` 或 `run_python`。
- 本阶段不解决通用脚本兼容、任意依赖、联网数据获取、模型训练、回归分析、数据清洗、图表渲染或多文件关联。

## 威胁模型与强制控制

| 威胁 | 典型方式 | 后续实现必须满足的控制 |
| --- | --- | --- |
| 提示注入 | CSV 单元格要求忽略规则、联网或读取密钥 | 数据不进入代码生成；固定模板不解释指令；日志和输出不回显无限文本 |
| CSV/公式注入 | `=CMD(...)`、超长公式或控制字符 | 单元格仅作为字符串/严格数值解析；不生成电子表格公式；输出 JSON 转义 |
| 路径穿越 | 文件名含 `../`、绝对路径、UNC 路径 | API 只接受 artifact ID；隔离层决定固定路径；拒绝路径和 URI |
| 符号链接与特殊文件 | 链接到宿主文件、设备或 socket | 只读输入必须验证为普通文件；禁止跟随链接；不挂载宿主敏感目录 |
| 资源耗尽 | 超大文件、超长字段、海量列、恶意数值、压缩炸弹 | 限制输入字节、行列数、字段长度、CPU、墙钟、内存、进程数、输出和文件数；超限强制终止 |
| 输出洪泛 | 巨量警告、stdout/stderr 或结果字段 | 输出 schema 和长度有硬上限；日志截断；超过配额封闭式失败 |
| 数据泄露 | 读取环境变量、源码、缓存或其他任务数据 | 环境变量白名单最小化；每任务独立临时目录；无共享可写状态；审计不保存原始敏感数据 |
| 残留与跨任务污染 | 临时文件、子进程或缓存未清理 | 任务后销毁隔离环境；验证无存活进程和残留文件；清理失败时不得复用目录 |
| 供应链风险 | 恶意包、漂移镜像或运行时下载 | 固定运行时和镜像 digest；不安装包；仅标准库；依赖和模板变更重新评审 |
| 沙箱逃逸 | 内核、容器、挂载或运行时漏洞 | P5-02 实测至少两种隔离方案；无网络、最小权限、只读输入、临时输出；发现可利用逃逸即停止接入 |

## 失败、审批与停止条件

- 编码、CSV 结构、表头、列类型、输入身份、大小或任何资源限制校验失败时不得开始或继续分析。
- Provider、模型、论文正文和 CSV 内容不能改变模板、运行时、预算、挂载、网络策略或权限。
- P5-04 Worker 沿用 P5-02 的 5 秒墙钟、1 CPU、128 MiB 内存、32 PID、1 MiB 输入/输出和 16 MiB tmpfs 上限；P5-05 已增加 CPU hard limit、共享 stdout/stderr 预算、单输出文件限制、超限原因码、进程内取消句柄和可靠清理观测。
- P5-02 若不能在 Windows/Docker 开发环境证明进程隔离、无网络、只读输入、临时输出、资源限制和可靠清理，则停止 P5-03 及后续生产接入。
- P5-02 已确认 Windows Job Object 无法阻止 socket、宿主 canary 和输入改写，因此淘汰；加固 Docker 候选全部强制探针通过，可继续 P5-03 建模，但生产执行仍未授权。
- 即使后续实现通过技术 benchmark，执行前审批、结果发布审批、审计模型和对抗测试仍是强制门槛，不能由 Agent 自行批准。
- 执行审批绑定完整 `taskDigest`；脚本、输入、运行时、镜像、限制或预期输出变化必须重新审批。发布审批只允许成功终态，并绑定任务、产物、警告和审计链头计算的 `publicationDigest`。

## 后续任务边界

- P5-02 只比较沙箱方案并确定可验证配额，不挂载生产路由。
- P5-03 定义 artifact、job、approval、audit 和 output 的正式模型；本文不预设其 wire schema。
- P5-04 仅提供内部 `run_job(job, input_path)`：输入只读挂载到 `/input/data.csv`，输出只允许写入任务临时目录的 `/output/statistics.json`；容器无网络、非 root、根文件系统只读、无 capabilities、启用 `no-new-privileges` 与固定 seccomp，环境仅保留固定 `PATH`。
- P5-04 及后续只能运行固定描述统计模板，不能扩展为任意 Python 或通用工具。
- P5-05 的同步 `run_job` 兼容入口由内部 `start_job` 执行句柄封装；取消、墙钟或资源超限时执行容器强杀、强制删除、残留核验和临时目录清理。清理失败只暴露阶段与残留数量，不暴露宿主路径或 Docker 原始错误，污染资源不得进入后续任务。
- P5-06 的 `code_execution_store` 是宿主信任边界：任务快照、独立脚本文本和审计事件单事务写入 SQLite，事件按序号、canonical payload 和前序 digest 形成 SHA-256 链。恢复或更新前验证完整链、链头、事件数、任务与脚本摘要，失败时不返回部分记录。
- P5-07 的全局审批中心只允许上传一个 UTF-8 `.csv`；服务端生成 opaque artifact ID 并复核大小与 digest。发布批准只设置 `publishable` 门禁，不自动进入研究报告、Agent evidence 或工作台。
- 审计事件只记录创建、审批、执行开始和执行结束的有界元数据。容器不挂载审计数据库；CSV、脚本文本、stdout/stderr、宿主路径、环境变量和凭据均不进入事件或 public trace。该方案用于发现宿主存储篡改，不替代数字签名或外部可信时间戳。
