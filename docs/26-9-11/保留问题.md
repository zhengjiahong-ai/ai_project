# 新风格前端保留问题

以下问题涉及现有接口语义或产品行为，本轮不虚构新的后端能力。当前实现先保留原有可用入口，待复核后再确定最终交互。

1. **阅读 IDE 左栏“标注”的归属**：现有数据同时存在 PDF 高亮与阅读笔记，两者不是同一列表。需确认“标注”标签应只展示 PDF 高亮，还是同时包含笔记；本轮继续保留目录导航，并通过右侧“笔记”入口访问阅读笔记。
2. **研究 Agent 的连续对话语义**：现有输入接口每次创建一个独立研究任务，尚无明确的“在同一任务中追加消息”接口。界面按项目下的任务列表展示，底部输入仍调用现有创建任务接口。
3. **Agent 的“加入阅读笔记”动作**：现有 Agent 产物保存调用工作台产物接口，并不直接写入阅读笔记数据。界面继续使用现有保存能力，待确认是否需要新增跨模块写入接口。
4. **深度研究与论文写作的最终入口**：现有两项能力挂在阅读 IDE 的功能标签中，而参考设计强调研究 Agent 承担项目研究。迁移前需确认后端任务模型与历史数据的兼容方式，本轮保留原入口。
5. **项目论文的编辑方式**：后端已有创建项目时提交论文集合的能力，但当前接口中未确认项目建立后的增删论文流程。本轮在新建项目面板中管理论文，不提供无法确认的编辑行为。
