# 对话、学习与阅读交互收敛

本批落实此前确定的七项交互改进。工作区仍对应任务；任务论文默认均可使用，显式选择材料收窄本轮范围，阅读焦点与对话材料分别保留。

| 项目 | 最终行为 | 验证 |
| --- | --- | --- |
| 保存不打断阅读 | 消息保存后中栏不自动切换。用户点击“查看笔记 / 查看成果”才打开对应记录。 | UnifiedTaskApp、ChatPanel 保存测试；第一批提交 583d684。 |
| 记录可辨认 | 导航记录显示类型、时间和正文预览。同名但内容不同的记录独立保留，历史版本不合并。 | taskDocumentNavigation 与根组件回归；第一批提交 583d684。 |
| 学习作答有明确入口 | 学习期间默认普通提问。“回答这道题”位于学习问题附近；作答时显示“提交回答”和退出入口。答案成功后回到普通提问。 | 学习状态回执、任务切换、显式作答与普通对话路由测试。 |
| 翻译自动且可控 | 首次进入未翻译页面的译文 / 对照视图自动翻译。切换不重复提交；运行时可停止；失败或停止后由用户重试，已有译文保留。 | 根组件使用真实翻译 Hook 和本地模拟响应，覆盖自动启动、切换去重、停止、迟到结果、重试；Hook 覆盖跨页和部分译文。 |
| 任务反馈简洁 | 当前活动和对应消息显示简短状态、停止 / 查询 / 重试。技术错误折叠；重试和停止仍使用原请求身份。 | ConversationExecution、任务操作和根组件恢复测试。 |
| 材料与问题分开 | 输入正文中不显示完整材料标记，选择以短标签呈现。标签可移除；编辑、展开输入和重载草稿保留范围及正文空格、换行。@补全使用同一方式。 | 材料选择、同名论文、草稿恢复、正文编辑、发送范围测试；实际浏览器截图。 |
| 新手入口随上下文变化 | 无论文可先解释概念；有多篇且未聚焦时先选择论文；有阅读焦点时可精读、解释或检查结论。已有对话的“下一步”折叠，非空草稿不被建议覆盖；学习中提供回到问题 / 完成本轮。 | 根组件上下文测试、ChatPanel 下一步与草稿保护测试。 |

验证命令均在 `frontend` 运行：

```powershell
npm test
npm run typecheck
npx eslint src/UnifiedTaskApp.jsx src/components/ConversationExecution.jsx src/components/TranslationPanel.jsx src/components/conversationProcessingModel.js src/hooks/usePageTranslation.js src/hooks/useTaskLearning.js
npm run build
```

完整测试：19组 Node 脚本检查、59个 Vitest 文件、417项测试通过。最后调整发送标签的材料判断后，54项根组件回归及类型检查再次通过。修改的 JavaScript / JSX 静态检查无错误；现有 ESLint 配置未覆盖 TypeScript，TS / TSX 通过 `tsc --noEmit` 检查。构建仍有原有依赖 `use client` 与大包体积提示。

浏览器验证在现有本地页面完成：材料选择变成独立标签，输入问题与换行保留，中栏成果保持不变；验收输入随后清空并恢复全部材料，没有发送问题或调用外部模型。截图：[材料标签与正文](interaction-refinement-evidence/material-chips.png)。

本批是交互验收，自动翻译通过本地模拟响应验证请求生命周期；没有增加真实模型质量复测，也不声称本批重新验收了模型回答内容。
