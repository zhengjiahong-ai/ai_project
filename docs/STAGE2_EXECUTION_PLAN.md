## 本阶段必须完成

1. 任务材料选择、@材料、显式单篇约束、多篇比较与歧义澄清。显式材料优先于活动，活动继续保留原材料，单篇指代以阅读焦点为主，普通问题默认任务材料；任务外材料不能进入调用。
2. 六种命令和自然语言共享服务端参数、执行、结果、错误与保存协议。补课和批判不能因材料严格限制而退化成只添加提示词的普通问答；前端不得依赖各能力旧接口拼接结果。
3. 综合 Agent 内部受控组合检索、解释、比较、批判和研究。简单解释只走轻量路径，显式研究才启动长任务；组合执行使用固定能力白名单、有限步骤与不可变材料快照，沿用阶段 1 的取消与请求身份。
4. 结果优先、来源收束、统一停止/失败/重试/保存；长成果在中栏查看和编辑。完善阅读就绪与可选分析分离、持久化上传处理状态，承接阶段 0 的 B05。
