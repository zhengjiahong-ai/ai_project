# 阶段6批次7：全景翻译保留原图与公式（2026-10-08）

## 问题与实现

四例真实验证中的 LightGaussian 第4页翻译，保留了原论文段落坐标，却没有绘制图表、独立公式等原始区域；正文因此出现大块空白，字号约10px。模型还返回了公式抽取碎片 `M HWX`。

新增图文译文组件，从同一 PDF 绘制当前页，在正文译文之间保留原始区域。中文正文以16px字号自然排版，不要求塞进原英文段落高度；宽阅读区支持双栏，窄阅读区依次阅读两栏。白色空区域裁去竖直留白，图表与独立公式仍来自原 PDF。含公式的段落同时显示原文公式上下文，其余段落的原文收起。未翻译区域保留原文。

原 PDF 渲染与模型请求独立；只切页时复用文档，切换论文时销毁旧加载任务，旧页渲染取消或迟到时不覆盖新页。原图载入失败时保留已完成译文及简短提示。图像只存在于当前组件内存，不写入本地持久化翻译状态。

新展示与保存成果共享过滤后的译文：不将独立公式、抽取碎片的缓存译文重新显示或保存。公式碎片过滤增加窄幅短变量串判断，保留正常缩写如 DNA；原始 PDF 区域仍可读。
