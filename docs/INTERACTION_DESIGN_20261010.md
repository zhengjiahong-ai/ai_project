# 统一学术助手交互设计

本设计基于当前实现与真实演示，覆盖已有功能的交互整理，不增加新的研究项目概念、不增加旧项目导入功能。

## 1. 产品边界与材料规则

- 任务是论文、对话、学习活动和成果的组织单位。
- 默认允许AI使用当前任务全部材料。打开某篇论文仅改变阅读焦点；提问明确指向“这篇”等单篇语义时，以当前论文为主；显式指定材料优先。
- 保留导航、内容、对话三栏及收起能力。精读、补课、自测、批判、比较、研究、能力组合从对话启动；翻译和划词工具在阅读区操作。
- 默认直接呈现结果。证据、执行细节、历史版本按需展开；仅在需要用户处理时突出状态和操作。

## 2. 各区域职责

| 区域 | 展示什么 | 不承担什么 |
| --- | --- | --- |
| 左栏任务导航 | 当前任务；论文与目录；笔记与成果；已结束学习记录 | 不展示执行流水或长篇正文 |
| 中栏内容区 | 论文原文/译文/对照；用户打开的成果、学习记录、证据 | 不因后台完成或临时状态自动换走用户正在看的内容 |
| 右栏对话历史 | 按提交顺序排列的问题、回答、活动与简短成果入口 | 不在顶部累积已结束活动 |
| 右栏输入区 | 可编辑草稿；本轮材料与学习输入方式；发送/停止 | 不放历史记录和长期错误堆栈 |
| 输入框上方当前活动条 | 简短活动名、状态、停止/继续/跳转待处理位置 | 不铺开完整问题、计划、来源或过程日志 |

顶部应用栏只保留任务标题、布局和全局入口。跨任务遗留草稿进入次级恢复入口；当前任务确有未同步修改时才在当前保存位置提示。

## 3. 左栏与中栏

左栏继续使用“论文与材料”和“笔记与成果”，后者含可折叠的“学习记录”。成果量多时提供搜索与类型筛选（笔记、报告、比较、译文），不用另开多个模块页面。

每项使用短标题和类型标识，悬停或打开后显示完整论文名。活动完成自动加入学习记录；报告、比较等已有自动保存成果按同一文档入口呈现；普通回答仍由用户主动保存。对同一回答再次保存应打开原成果，显式“另存副本”才新增。

打开学习记录后，中栏显示：短标题、论文、活动类型、结束/暂停状态，按问题组织作答、反馈和必要的提示/补课记录。仅展示真实保留的数据；不以“已结束”暗示“已掌握”，不把暂停、跳过标为通过。历史记录默认阅读，不重新启动模型；继续学习须由用户明确触发。

中栏顶部保留“论文 / 当前打开的成果或记录”轻量切换；原文/译文/对照属于论文内部视图。返回论文恢复页码、缩放、滚动位置；返回成果恢复正文位置和未保存修改。刷新恢复最后打开对象，若不可读取则给就地提示并保留已有数据。

证据引用打开对应论文并定位；保留回到成果的位置和入口。右栏对话滚动位置不随中栏切换改变。无需把每份证据作为常驻标签打开。

## 4. 对话与活动的统一生命周期

每条提交建立稳定的消息锚点，活动状态、返回结果和重试记录关联该锚点。异步完成更新原位置，不追加到最新问题后。研究、学习和组合调用复用现有requestId、researchId、activityId及artifactId建立关联，展示调整不重复生成内容。

| 阶段 | 对话中的呈现 | 当前活动条 | 左栏 |
| --- | --- | --- | --- |
| 已提交/生成中 | 原问题下出现简短生成状态 | 处理类型、停止 | 不提前建立空成果 |
| 等待用户操作 | 原位置展开问题、计划或需要处理的内容 | “待确认计划/待回答”等，点击定位 | 暂停学习可通过记录入口找回 |
| 暂停 | 原位置折叠为“学习已暂停”，提供继续 | 用户转做其他内容后不长期占位 | 保留暂停记录，状态明确 |
| 已生成 | 直接答案或简短结果入口 | 不再显示“生成中” | 已自动保存的成果可打开 |
| 部分完成 | 可用结果与一句具体限制 | 有待处理动作时保留简短提示 | 状态保留为“部分结果” |
| 失败/停止 | 原位置显示原因、已保留内容、适用的继续或重试操作 | 未处理错误提示可收起；不永久固定历史错误 | 已有部分成果仍可访问 |
| 已结束/已保存 | 简短成果入口或学习结束摘要 | 退出当前活动条 | 成果/学习记录归档 |

当前活动条至多一行；同任务有多项活动时显示数量和可展开列表。待确认内容仍留在对话原位置，用户可以先处理其他问题。用户向上阅读时不强制滚到底部，显示“有新结果”入口。

研究“已完成”表示流程结束，不代表所有事实已证实。生成状态、保存状态与内容限制分开表述，不用同一个绿色完成状态替代。

## 5. 各功能的具体流程

### 精读与自测

对话给出当前问题，输入框上方显示“精读作答 · LightGaussian”或“临时追问”，可直接切换。回答与提问的含义可见；不让普通聊天在无提示情况下被当作答题。提示、补课、跳过收进“学习操作”，暂停和结束保持易达。发送其他功能时保留原学习进度，明确进入新操作的输入方式；回到学习需选择继续。

结束时对话只留下“本次精读已结束 · 查看记录”等短入口，可补充一句未掌握内容。详细作答与反馈从左栏或此入口在中栏打开。新手的下一步建议限一项，不持续铺开控制条。

### 普通问答、补课、批判、比较和能力组合

统一显示直接答案；已有长成果显示简短摘要和“打开成果”。先回应用户的范围和长度要求，详细表格、推导或完整分析进入成果。组合只产出一份统一结论及一个成果入口，避免依次重复概念解释。

普通回答的“保存”和已有成果的“打开”互斥展示；不再并列要求用户先理解“收藏到学术笔记”和“保存为成果”。保存后可改名、编辑和移动；成果类型作为次级信息。

### 研究

1. 原消息下生成短标题与待确认研究问题；完整指令保留在用户原消息，卡片不复述。
2. 修改问题后执行；运行时显示一行状态，过程按需展开，不输出长流水。
3. 报告生成后在原位置给“查看报告”和确有必要的确认操作，打开中栏不会丢失阅读位置。
4. 保存后更新为“研究报告｜剪枝与SH降阶的消融实验方案 · 打开报告”。左栏为同一份报告；顶部不保留研究卡。
5. 证据进入报告；聊天可保留小型引用入口，不在完成卡重复铺陈来源。真实证据覆盖不足时，在结论旁一句话说明，并保留详细边界。

### 划词解释

小浮层先显示所选片段与简短解释，完整解释和追问进入对话并关联原文。浮层可收起，Escape关闭；翻页、切换论文、任务或打开成果时收起浮层，原划线与解释保留，可再次点击找回。无需把一次解释长期覆盖在当前阅读内容上。

### 翻译

保留原文/译文/对照；页码与处理状态放在该阅读工具内。生成完成直接显示译文，不向全局对话添加翻译完成卡。保存按钮经历“保存中 → 已保存/打开成果”，同页同一译文重复点击不新建副本；再次生成产生新版本。失败只影响该页，不挡住原文阅读或其他问答。

### 上传、解析和论文概览

状态归属论文行与当前阅读区。解析中可以先读原文；完成后收束为小标识，不常驻大状态栏。概览在论文内容区提供一次明确入口，生成完成不自动替换用户正在阅读的页。

### 保存、编辑与历史版本

名称点击可直接编辑；保存状态紧邻对应内容。历史版本、移动、导出放入次级工具区。未确认请求先查询原请求；不把点击再次保存作为恢复方法。用户切换内容时保留草稿，原文件和草稿状态分别可见。

## 6. 材料选择与输入

输入框旁默认简写“任务材料 2 篇 · 当前 LightGaussian”。明确单篇语义时显示“主要参考 LightGaussian”；显式@材料显示可移除短标签。选择“本任务全部材料”与“指定材料”即可，用户不必接触内部范围字段。

输入/提问变化后可预览已识别功能，但不强迫每轮确认意图。斜杠显式选择优先，功能名称短标签可取消；生成期间允许编辑下一条草稿，发送与停止的状态清楚。使用中文输入法确认候选时不误发送。切换任务保留各自草稿，不把未发送材料选择串到另一任务。

## 7. 已确认的同类问题与程度

| 当前功能 | 现状与影响 | 改动 |
| --- | --- | --- |
| 学习记录 | 已修紧凑样式，但仍常驻对话顶部，信息归属未修 | 移到左栏；点击中栏打开 |
| 研究 | 所有研究记录独立于消息列表渲染，完成后仍在顶部，全文问题重复 | 移入原对话位置，完成收束为成果入口 |
| 活动处理状态 | 请求状态、正在处理控制条、学习条和聊天加载提示可能重复 | 同一活动只保留一个当前状态入口 |
| 失败/停止恢复 | 成功请求已隐藏；最新非成功请求仍常驻顶部，其他请求折叠 | 锚定原消息，当前异常可收起且可找回 |
| 划词浮层 | 解释内容较长，会遮挡论文；阅读位置改变时可与原片段脱节 | 精简、收起、关联原位置 |
| 材料范围提示 | 在消息滚动内容开头，后续输入时不易看到 | 移到输入框附近，短标签按需展开 |
| 笔记/成果保存 | 两个并列保存动作，容易形成重复副本 | 一个保存入口，已有结果改为打开 |
| 译文保存 | 当前按钮未管理保存进行中与已保存状态，连续点击可能新增重复成果 | 保存状态与同页版本身份绑定 |
| 错误与草稿 | 多类错误汇总到全局底部；遗留空草稿入口出现在当前任务栏 | 就地归属，跨任务记录进入次级恢复入口 |
| 阅读与成果切换 | 刷新回到论文，未恢复正在查看成果 | 保存并恢复当前对象和阅读位置 |

并非所有功能都需要移位：翻译、原图放大、版本历史、导出本来归属中栏，保留其位置；主要整理默认展开程度、反馈和返回路径。

## 8. 实施顺序与验收

1. 信息归属：学习记录迁到左栏/中栏；研究关联到对话原位置；已完成项不再占据顶部。复用已有存储，不新增模型调用。
2. 状态合并：统一当前活动条、待处理定位与失败恢复；生成期间保留可编辑草稿。明确多活动与任务切换，不丢原请求。
3. 阅读连续性：论文/成果/证据往返位置恢复，划词浮层生命周期和刷新恢复。
4. 保存与结果整理：统一保存入口、译文重复保存处理、结果简洁性与组合去重；前端修改和模型输出调整分别验证，真实模型案例仅在必要时按统一授权执行。

验收应覆盖：完成10次活动后顶部仍不累积卡片；长论文名在窄栏不撑开布局；学习暂停、结束与掌握状态不混淆；研究待确认可离开再回来；请求乱序完成仍更新各自原位置；失败恢复不重复提交；学习/报告/译文从左栏可找回；来源计数明确是证据片段；证据定位后可返回原成果位置；切换与刷新保留草稿；翻页后解释不遮挡无关页；连续保存同一内容不产生副本；鼠标与键盘均可操作；输入框始终可见。
