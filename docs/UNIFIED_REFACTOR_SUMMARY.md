# 统一任务式学术论文助手：重构重点

本次重构将单论文阅读与多论文研究整合为一个面向新手的任务式论文助手。

- **一个任务组织全部内容**：论文、对话、学习记录、笔记与成果归属同一任务。默认使用任务材料；明确单篇指代以当前论文为主，显式指定材料优先。
- **统一三栏界面**：左侧寻找材料与记录，中间阅读论文或编辑成果，右侧交流；支持收起、调宽、专注模式和窄屏适配。
- **功能回到对话**：自然语言与 `/精读 /补课 /自测 /批判 /比较 /研究` 共用执行路径，复杂需求内部组合；翻译、划词与标注保留在原文附近。
- **面向理解的学习与分析**：学习依据作答反馈调整，支持暂停、继续和临时追问；批判以完整观点组织，比较保留实验条件，研究形成可执行方案。结果优先，来源与过程按需展开。
- **可靠保存与找回**：支持搜索、原对话定位、草稿、历史版本、冲突处理、移动和导出；稳定关联请求、成果、版本及证据，防止跨任务串写和重复执行。
- **前端产品化整理**：统一标题、工具栏、输入区、浅深主题和局部状态；完成学习归入历史，可点击引用展开对应依据，原文往返保留阅读位置。
