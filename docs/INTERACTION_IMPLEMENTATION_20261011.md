## 查找入口的边界

- 搜索范围为当前任务；跨任务先切换任务。
- 学习记录只打开实际保留的问题、作答和反馈，不重新生成。
- 已删除、从未保存或服务端不可读取且无本地备份的数据不能保证恢复。
- 服务不可用时，处理记录明确提示列表可能不完整；已有论文、对话、成果和学习记录仍保留入口。

## 检查结果

- 前端完整回归：52文件、349项通过；最后暂停/结束入口调整后根界面37项再次通过。使用 `vitest run --maxWorkers=4`；此前默认并发运行的公式图片异步断言出现一次超时，限制并发后的完整复核通过。Node烟雾检查也通过。
- TypeScript检查通过；生产构建通过，仍有既有大包警告。修改的JavaScript文件ESLint无错误或依赖警告；PDF TypeScript由类型检查和运行测试覆盖。
- 组合结果在当前Python容器离线回放43项通过，覆盖前置解释＋比较、长依据末尾引用、部分结果、句子去重及显式字数；模型使用测试替身。
- 本地服务已恢复。Python `/health` 的GROBID、RAG检查均为ok；Java读取演示任务16条请求均成功，界面显示16条逻辑记录，不重复列出研究创建请求。未重提任何原请求。
- 实际浏览器已核对：学习搜索/打开/刷新恢复；原研究问题搜索定位；打开同一份已保存报告；处理记录搜索“暂停学习”仅命中1条，点击可关闭弹窗并返回原对话。
- PDF真实刷新：第4页、125%缩放、页内偏移3186在刷新前后相同。报告证据定位到第8页，返回后证据仍展开、正文偏移144保持。
- 真实PDF高亮：选区菜单和颜色按钮位于同一浮层；标记在刷新后保留；Escape关闭、重新点击打开、翻页关闭、打开成果关闭均通过。使用无需模型调用的高亮标记核对生命周期，长解释折叠由组件回归覆盖。
- 390×844窄屏：页面宽度390，无横向溢出；输入框底部801，位于视口内。导航焦点进入当前任务，Escape关闭并恢复触发按钮。测试结束已取消视口覆盖并恢复并排布局。
- 此轮未新增真实模型请求，未导入旧研究项目，也未重复用户已省略的新手全流程或独立Edge恢复。
